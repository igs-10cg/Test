# Unsere Umwelt – Schulprojekt

Eine einfache Website zum Thema Klimawandel. Sie besteht aus HTML-Dateien und einer gemeinsamen CSS-Datei.

## Dateien

- `index.html` – Startseite
- `klimawandel.html` – Erklärung des Klimawandels und mögliche Folgen
- `ursachen.html` – Ursachen des Klimawandels
- `loesungen.html` – Maßnahmen im Alltag und gemeinsam
- `style.css` – gemeinsames Design für alle Seiten

## Lokal ansehen

Öffne `index.html` im Browser. Alle HTML-Dateien und `style.css` müssen im selben Ordner liegen.

## Auf GitHub Pages veröffentlichen

1. Lade alle Dateien in das Repository hoch.
2. Öffne **Settings → Pages**.
3. Wähle bei **Build and deployment** die Quelle **Deploy from a branch**.
4. Wähle den Branch `main` und den Ordner `/(root)`.
5. Klicke auf **Save** und warte, bis die Website veröffentlicht wurde.

Die Navigation funktioniert über die Dateinamen, daher müssen alle Dateien im selben Ordner bleiben.
